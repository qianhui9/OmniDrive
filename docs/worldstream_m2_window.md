# R0 M2 窗口与全局更新

唯一正式接口为 `IncrementalVisionRuntime.forward_from_m1`，内部调用同一 `_forward`、刷新规划器、WindowExecutor 和原子 StateCache。完整计算是同一执行器更新全部窗口，不切换备用模型。

保留真实 Conv2d 依赖闭包、历史来源校验、逐窗口年龄、区域状态事件、必须/普通刷新、Block0/1 局部计算和全局锚帧/残差更新。R0 普通预算3、最大窗口复用年龄8、全局间隔2、漂移阈值0.7721027880907059；完整参数以 `configs/worldstream_r0.json` 为准。

旧离线 A/B/C/NoM1Region 与匹配算力入口、成本证书晋升工具已删除。测试直接调用真实 serving 接口，不再绕经 D 别名。窗口跳过比例不能替代完整系统加速比。

执行代码的浮点运算与缓存发布逻辑未因本次 M3 路线删除而改写。单元测试覆盖依赖、局部强制刷新、来源失效、年龄、事务和真实 CUDA 输入形状；完整模型结果仍须通过 Native/R0 配对收据评价。
