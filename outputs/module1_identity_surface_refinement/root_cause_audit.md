# Phase 1 根因审计（修改核心代码前）

上一轮源码已完整留存于 baseline_source/。复核了最新报告、协议、原始 association/foreground/pixels/state trace 及核心 M1 源码。本轮旧 Calibration 的 20 个场景只作为 Development。逐帧重放 Local R12、独立 LiDAR/annotation 评分，精确复现 1336 个接受中的 169 个错误；完整像素证据见 traces/phase1_false_stable.jsonl 和 visualizations/。

1. 原前景生产器候选稀少：它同时要求可访问的上一实际来源帧、可三角化视差、双框 OBB 成员、三象限支持、可测深的外围环、前后两时刻深度分离、无任一视图静态矛盾。Calibration 30768 个对象-相机检查中，大部分缺源观测或不满足可观测/框成员，且静态对象与背景可能等深。这是声明强度/可观测性与候选门槛的交集，不只是计算慢。
2. 身份连续性本身不要求对象静止、环深度分离或精确中心。独立选择性身份资格可以替代像素前景证明，但不能省略实际质量评价，不能据此认证三维表面。
3. 原 local=0 Calibration 的 5198 个保留几何候选中，2646 可评分、12 错误，2552 不可评分。存在值得研究的正确身份子集，但整体身份资格不能由这些条件 Precision 推出。新方法选择“无门内竞争、短距离实际检测更新、有实际图像轨迹/裁剪观测”的有限人口，不能在线使用 GT 判定人口成员。
4. 错误稳定点的光度残差中位数约 0.00405、FB 中位数 0.142 px、Jacobian 中位数 1.010，全部通过已有门槛。169 点均未由 annotation 确认运动；46 点视差不足 0.5 度。其余 123 点保留 Unknown Root Cause：相似纹理的错深度、表面切换和稀疏参考误差均不能凭误差大小区分。现有两条射线可以为错误光流求出自洽三维点，重投影一致不是独立表面证据。
5. 可修复部分包括低视差仍接受、缺少额外时间基线约束、以及 Post-Commit 认证没有对外查询闭环。无法观测部分包括 A/B 的真实表面归属、未标注像素、超出2m/竞争的对象身份和真实 pose/calibration 残差，必须继续 Unscorable/Unknown。
6. 不增加大模型的最小试验：身份声明独立；局部表面采用三帧、双时间基线的射线重投影与对应闭合，复用当前/上一 dense source map，另测更长基线的双向流。它是待验证的有限 RGB 观测声明，不是物理真值。保留两帧仅可观测性消融，固定原门槛，不搜索新 radius。

## 统计与时序约束

零错误的 scene/log 事件 CP95 上界为 1-0.05**(1/n)，至少59个独立接受 scene/log 才可能≤5%。当前尚未曝光的完整新日志仅12个，冻结为4/4/4 Calibration/Heldout/Final；模型 Train Population 与模型独立测试明确分开。因此本轮最多提供可行性证据，不能以点数或重复帧补足正式物理资格。

Precheck 结果不得反填当前检测信息。保留 commit 返回契约，新增 get_current_certifications()：仅返回原子发布后仍匹配当前 geometry/version/frame/scene/epoch/timestamp 的防御性只读快照，reset/异常/替换不得暴露新证书。

GT/annotation/LiDAR 只在 tools 评分；运行时规则不依赖离线身份、实例 mask 或参考深度。严格前景生产器完整保留。不满足必要条件只能拒绝，不能用高检测分数或手填布尔值批准身份。
