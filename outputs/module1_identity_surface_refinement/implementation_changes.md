# 本轮实现与结果边界

## 实现

- 新增 `worldstream/m1/identity_continuity.py`。独立的 `object_identity_continuity` 声明只针对同一物理实体对应，不认证静止、米制位置、速度或 Box 表面。采用无门内竞争、上一实际来源、≤0.5m检测更新和实际双向轨迹/共有视图裁剪支持，资格依赖独立真实身份验证。没有前景 Mask，也没有把几何关联直接批准为身份。
- 保留原严格 `foreground_correspondence.py` 和静态射线声明。认证器复用实际测量回执/来源/版本检查，并为新声明检查独立的生产器、人口、传递源码/配置协议和 scene/log 风险资格。没有真实资格时仍拒绝；哈希不作为质量证明。
- 新增 `M1CommitCertification` 和 `get_current_certifications()`。`commit()` 返回契约不变。查询只暴露已原子提交、当前 scene/frame/version/epoch/timestamp 匹配的证书，返回 frozen bundle 和防御性 provenance 副本；绝不向此前的 Precheck 字段反填当前检测信息。新几何清除旧证书，reset/异常/pending 边界保持。
- 新增 `surface_visibility.py`。三帧射线/对应闭合用于检验两帧自洽深度：当前—上一三角化必须解释独立测得的当前—前两帧对应，且直接/复合轨迹一致。使用原 FB、射线、纹理和 Jacobian 基础；低视差/历史不足/闭合未知返回 Unknown。保留动态扫过保护，无半径搜索、新网络或在线 GT。
- 三帧额外历史仅保留一组旧相机及上一 source map，采用不可写数组，随原子提交发布、reset清空，规模不随序列增长。
- 新声明和新区域策略均为显式研究开关。默认仍关闭身份生产器、保持原区域策略；新研究配置没有批准的资格，不供后续模块正式消费。
- 原模型采集工具仅增加可选输出根目录参数，复用完全相同的原感知构建、预处理、checkpoint和推理设置。没有修改 M2/M3、项目模型源码、权重、Checkpoint 或 LoRA。

## 实际证据

修改核心代码前重放旧 Calibration 20 场景，精确复现 Local R12 的169个可评分错误稳定点，46点可确认低视差，其余123点保持 Unknown Root Cause。双向流/光度/重投影通过并不足以证明相同真实表面，不能据此把未知原因主观分成前景/背景或表面切换。

旧20场景/240帧作为本轮Development；另在12个对旧M1记录新的场景/采集log中，冻结4/4/4分组并由原checkpoint实际采集144帧预测。合计32场景/384个唯一质量帧，每帧运行5种真实策略和Full Refresh参考。新数据仍属于模型Train Population，不是原模型泛化测试。新token仅在旧可用性清单出现，未匹配旧M1质量产物。

Development 的 B 有175个候选，144个独立可评分正确链接，31个不可评分；可评分支持仅4场景，条件场景上界仍52.71%。新Calibration候选为0，冻结选择结果为None，随后没有调参或重选。Heldout描述性观察到2个正确候选（1场景），Final为0。它们不能替代Calibration失败或整体资格，真实持久认证仍为0，FAR及正式上界为null。

三帧方法减少错误数，但有效覆盖接近零、可评分接受不足，未取得满足风险约束的覆盖收益；没有将“全Unknown”当作成功。两帧可观测性消融仍有错误，说明只加视差门槛不能解决全部错误。完整逐像素轨迹、实际RGB/Mask图、独立参考和原口径分母均保存。

## 验证和成本

保留原380项测试，新增23项，包括实际受控身份测量/资格、Post-Commit查询、防御性边界、异常不发布、签名GT拒绝、声明不扩张、58/59独立单位边界、三视图非零平面、低视差/时间/表面冲突、遮挡、刷新与历史上限。真实CUDA完整回归为403 passed，零跳过。受控正例只作为工程测试，不计入真实质量接受。

原模型8帧实际GPU感知/backbone/head memory数值一致、隔离CPU声明路径成本消融和40帧旧开发序列生命周期验证见对应JSON/日志。成本消融对照A开关前后的B测量/判定及保守Mask逐帧一致；新表面策略本来改变Mask，单独承担完整质量评价，不能伪称计算等价优化。

独立接受scene/log至少需要59个零错误单位；新Cal选择排除后仅8个评价log，即使理想零错也至少还缺51个，且当前不可评分身份人口仍未解决。未签发真实资格，未继续扩大P1运行时优化；所有结果以experiment_report.md及formal_go_nogo.json为准。本轮固定方法未通过不等于证明所有轻量身份/表面方法都不可能。
