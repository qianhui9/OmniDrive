# Frozen code semantics reference

This documents the already executed grading code; it does not revise the pre-GPU protocol. Vehicle selectors expand to car, truck, bus, trailer, construction_vehicle, motorcycle and bicycle. The existing annotation reader maps human.pedestrian.* to pedestrian, vehicle.construction to construction_vehicle, and the existing nuScenes vehicle subclasses to their detector taxonomy. Matching is class-independent3D-center distance<2m, unique nearest margin>.5m, one-to-one across all current detections; a second-choice Hungarian assignment cannot become a certain identity. Question nearest ranking uses planar ego distance; ROI<=50m, directly abs(y)<=4m and requested sign directions. Visible GT requires projected center in at least one original1600×900 camera at its exposure pose, nuScenes visibility>=3 and nonzero lidar+radar support. This is a visibility proxy, not per-pixel human confirmation. Projected uncertain-visibility GT within nearest distance+2m invalidates certification. GT targets within2m planar rank difference are identity-ambiguous; if all imply the same Position sector or Category, answer facts may be known while identity remains UNKNOWN. Answer directions use x>1 front, x<−1 rear, y>1 left, y<−1 right; within .5m of these boundaries is ambiguous. Positive Existence accepts any visible in-ROI witness, never requires a nearest identity and never treats absence of annotations as a correct No. Object and target metrics cover C proposal anchor receipts; they are not whole-detector AP or independent instance IDs for free-form B answers. Requests without a prediction-anchor receipt are separately counted: their missing_annotation_support reason means the answer-to-instance link is unavailable, not that the nuScenes annotation table is absent. Conditional proposal and actual-fast denominators are also reported. Unsupported natural/fixed QA uses only exact current-frame original QA limited fact recall, never a previous frame reference. Grading source hashes and the pre-evaluation selection freeze are retained; UNKNOWN is excluded from accuracy numerators and reported in all denominators.
